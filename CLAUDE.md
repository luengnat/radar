# CLAUDE.md

Evidence-ledger workspace investigating Thai weather-radar procurement
(TMD and Royal Rainmaking Department). No application code; the deliverable
is the ledger itself.

## Non-negotiable discipline

1. **Evidence tiers**: Verified (linked primary government document) /
   Reported (secondary report or supplied dossier) / Unverified (lead).
   Never upgrade a claim's tier without the source document linked inline.
2. **Language discipline**: never write "ฮั้ว / collusion / ล็อกสเปก /
   locked spec / overpriced / single bidder" as fact. Approved framing:
   "the records raise a question that needs the bid-opening and technical
   evaluation documents." Patterns justify document requests, not
   conclusions.
3. **Comparisons must be normalized**: never compare 425M vs 475M vs 480M
   packages directly. Split radar core from civil works, tower, solar,
   buildings (e.g. reported splits: radar core ≈418–427M of a 480M package).
   International comparisons (Singapore, PAGASA) are scope-incomparable
   unless maintenance scope and tower ownership match.
4. **Not proven to exist** (do not assert): common ownership, bid rotation,
   agreements not to bid, TOR locked to one OEM (both Leonardo METEOR 700S
   and EEC DWSR-8501S appear to fit the reported TOR envelope), inflated
   reference prices, official benefits.

## Workflow

- New findings → add to `evidence-ledger.md` in the correct tier, with the
  required-proof column filled, before writing any summary/prose.
- Top document requests (already ranked in the ledger): the written
  technical-evaluation reports explaining why the lowest bidder failed in
  all four FY2569 tenders; the original three quotations + TMD's request
  letters; MALs (Manufacturer Authorization Letters) per tender; TOR
  compliance matrix vs Leonardo and EEC datasheets line by line.
- Publication language rules are in the ledger's final section; check
  every draft against them.
